# Benchmarks

Generated by benchmarks/run.py on Python 3.12.10
(Windows-11-10.0.26300-SP0). Times are the median of 3-5 runs; lower is better.

| Case | Time | Notes |
| --- | --- | --- |

| parse scene (5000 lines) | 68.31 ms | parse_yaml() on a synthetic scene |

| parse ANSI log (1.0 MB) | 136.0 ms | 3942 lines, 1.0 MB |
| parse ANSI log (3.0 MB) | 547.83 ms | 11826 lines, 3.1 MB |
| parse ANSI log (5.0 MB) | 1121.64 ms | 19710 lines, 5.2 MB |

| render + PNG encode 40 rows | 500.78 ms, 286.7 KB PNG | full render path including disk write |

| render the bundled gallery (6 scenes) | 1218.27 ms | load_scene() plus render_scene() for every examples/*.yaml |

Rows are rasterised at 2x unless the case says otherwise, because 2x is the
default and the slowest common path. Timings include font loading on the
first call, which is why they are medians rather than minimums.
